## 📱 Featured Project In-Development

### 🔍 Lazy Tracker (An Accountability & Focus Ecosystem)
*A smart mobile companion designed to bridge the gap between "what we plan to do" vs. "what we actually do."*

* **The Problem:** People set idealized schedules but get easily distracted by social media, or claim they are "too busy" while wasting time on their phones.
* **The Solution:** A clean, 2D animated minimalist Android/iOS application that pairs a dual-timeline calendar planner with deep device background native API calls (`UsageStatsManager` & `DeviceActivity`). 
* **Core Mechanisms Built:**
  * **Automated Device Auditing:** Triggers high-priority "busted" motivational notifications if a user opens a distracting app (like TikTok/Instagram) during a blocked focus/study window.
  * **Biometric & Health Reminders:** Automatically tracks desk-sitting tasks and triggers a 40-minute prompt encouraging physical movement.
  * **Core Focus Module:** Built-in 20-minute specialized language practice timers (currently tailored for Japanese learning).
  * **Mindfulness Integration:** Morning modules pushing daily spiritual alignments, blessings, and dynamic inspirational video links to start the day with purpose.
* **Stack:** Android Native Kotlin / Flutter, Firebase, Secure Hardware KeyStore encryption.
